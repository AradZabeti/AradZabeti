# Code of Conduct

## Our standard

This project aims to be a respectful, constructive and technically focused space. Be clear, considerate and open to useful feedback.

## Expected behavior

- Treat people with respect.
- Focus criticism on ideas and implementation, not individuals.
- Give actionable technical feedback.
- Respect different levels of experience.
- Keep discussions relevant to the project.

## Unacceptable behavior

Harassment, personal attacks, discrimination, threats, doxxing, deliberate disruption, or sharing private information without permission are not acceptable.

## Reporting

For security issues, use the process described in [SECURITY.md](./SECURITY.md). For other conduct concerns, contact the repository owner through the public contact details in the profile.

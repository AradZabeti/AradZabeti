# Contributing to Arad Zabeti

This repository is primarily a personal developer profile and portfolio, but useful technical feedback and focused improvements are welcome.

## What fits here

- Bug fixes affecting the portfolio or resume pages
- Accessibility and responsive UX improvements
- Documentation improvements
- Performance and security improvements
- Small, focused maintenance changes

## Before opening a change

1. Keep the scope focused.
2. Do not add invented achievements, employers, certifications, statistics, or project claims.
3. Keep personal links and branding consistent with the profile.
4. Test the affected HTML, links, and responsive behavior before submitting.
5. Never commit API keys, tokens, passwords, private URLs, or other secrets.

## Pull requests

A useful pull request should explain:

- What changed
- Why it changed
- How it was tested
- Any screenshots or live URLs that help review visual changes

For visual changes, screenshots at desktop and mobile widths are especially useful.

## Content policy

This is a personal profile. Accuracy matters more than hype. Project descriptions should stay grounded in work that can be demonstrated or documented.

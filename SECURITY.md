# Security Policy

## Reporting a vulnerability

If you discover a security issue in this portfolio, please report it privately by email to **arad23426@gmail.com**.

Please include:
- a short description of the issue;
- the affected page or file;
- clear reproduction steps, if available;
- the potential impact.

Please do not publish credentials, tokens, private data, or an exploit before the issue has been reviewed.

## Scope

This policy covers the public portfolio and its client-side JavaScript, GitHub Actions workflows, and static assets in this repository.

## Security approach

The project uses automated secret-pattern checks, dependency/security features provided by GitHub, URL validation for dynamic navigation, and safer handling of external links. Client-side controls are defense-in-depth and are not a substitute for secure server-side validation.

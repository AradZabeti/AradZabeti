# Interactive Terminal

The profile terminal lives at [`/terminal.html`](../terminal.html).

## Commands

| Command | Purpose |
| --- | --- |
| `help` | Show available commands |
| `about` | Profile and current focus |
| `projects` | Selected projects and links |
| `stack` | Technologies and tools |
| `music` | Music technology and trumpet context |
| `resume` | Open the CV |
| `contact` | Contact and profile links |
| `clear` | Clear the terminal output |

## Interaction

- `Enter` runs a command.
- `↑` / `↓` navigate command history.
- `Tab` completes a known command.
- `Ctrl + L` clears the output.

The terminal is intentionally client-side and self-contained. It does not execute operating-system commands and does not send user input to a backend.
